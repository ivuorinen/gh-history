# JSON output reference

Every key `gh history --format json` writes, with its JSON type and meaning.
Dates are `YYYY-MM-DD` days in the report's time zone, `date_range.time_zone`.

This file is generated by `mise run docs` from
[`examples/report.json`](../examples/report.json). Edit the field list in
[`tools/jsondoc/main.go`](../tools/jsondoc/main.go), not this file.

## Top level

| Key | Type | Meaning |
| --- | --- | --- |
| `username` | string | The GitHub login the report is about, in the account's own spelling. |
| `date_range` | object | The period the report covers. |
| `generated_at` | string | When the report was made, just after its data was fetched, as an RFC 3339 timestamp in the report's time zone. `pr_merge_rate` and `issue_close_rate` count each item by its state as fetched, no later than this. |
| `summary` | object | The summary figures. Text, Markdown and HTML show the same figures. |
| `contribution_totals` | object | GitHub's own contribution counters for the period, private repositories included. |
| `events_by_category` | object (category → number) | Events per category: `pull_requests`, `issues`, `reviews`, `comments`, `repos` or `other`. Categories without events are left out. |
| `events_by_type` | object (event type → number) | Events per event type; the types are listed under `events[].type`. |
| `events_by_date` | object (date → number) | Events per day. Days without events are left out. |
| `events_by_weekday` | object (weekday → number) | Events per day of the week in the report's time zone, keyed `0` (Monday) to `6` (Sunday). Weekdays without events are left out. |
| `events_by_hour` | object (hour → number) | Events per hour of the day in the report's time zone, keyed `0` to `23`. Hours without events are left out. |
| `calendar` | object or null | GitHub's contribution calendar for the period, private repositories included; null when GitHub returned no days. |
| `streaks` | object | Runs of consecutive active days. A day is active when the calendar counts a contribution on it or, without a calendar, when it has an event. |
| `top_repos` | array of objects | Every repository with events, most events first, ties in name order. Text, Markdown and HTML show the top 15. |
| `commits_by_repo` | array of objects | GitHub's commit count for every repository with commits in the period, private repositories included, most commits first, ties in name order. |
| `events` | array of objects | The events the summary and the distributions are counted from, newest first. |

## `date_range`

| Key | Type | Meaning |
| --- | --- | --- |
| `start` | string | The first day of the period. |
| `end` | string | The last day of the period, included. |
| `time_zone` | string | The IANA time zone every day and hour in the report is counted in, such as `UTC` or `Europe/Helsinki`. |

## `summary`

| Key | Type | Meaning |
| --- | --- | --- |
| `total_events` | number | The number of entries in `events`. |
| `commits` | number | Commits in the period, private repositories included: GitHub's count, the same as `contribution_totals.commits`. |
| `prs_opened` | number | Pull requests opened in the period. |
| `prs_merged` | number | Pull requests opened in the period and merged within it. |
| `prs_closed` | number | Pull requests opened in the period and closed within it without being merged. |
| `pr_merge_rate` | number | The percentage of the pull requests opened in the period that were merged when they were fetched, unrounded. |
| `issues_opened` | number | Issues opened in the period. |
| `issues_closed` | number | Issues opened in the period and closed within it. |
| `issue_close_rate` | number | The percentage of the issues opened in the period that were closed when they were fetched, unrounded. |
| `reviews` | number | Pull request reviews submitted in the period. |

## `contribution_totals`

| Key | Type | Meaning |
| --- | --- | --- |
| `commits` | number | Commits. |
| `issues` | number | Issues opened. |
| `pull_requests` | number | Pull requests opened. |
| `reviews` | number | Pull request reviews submitted. |
| `repositories` | number | Repositories created. |

## `calendar`

| Key | Type | Meaning |
| --- | --- | --- |
| `total_contributions` | number | The sum of `count` over `days`. |
| `reported_total` | number | The calendar total GitHub reported, summed over the year chunks the period is fetched in. |
| `days` | array of objects | One entry per day of the period, oldest first. |

## `calendar.days[]`

| Key | Type | Meaning |
| --- | --- | --- |
| `date` | string | The day. |
| `count` | number | Contributions GitHub counted on the day. |
| `weekday` | number | The day of the week, `0` (Monday) to `6` (Sunday). |

## `streaks`

| Key | Type | Meaning |
| --- | --- | --- |
| `longest` | number | The longest run of active days in the period. |
| `longest_start` | string or null | The first day of the longest run; null when no day was active. |
| `longest_end` | string or null | The last day of the longest run; null when no day was active. |
| `current` | number | The run that reaches today or yesterday; 0 when the period ends before today or no run reaches yesterday. |
| `current_start` | string or null | The first day of the current run; null when `current` is 0. |
| `active_days` | number | Active days in the period. |
| `total_days` | number | Days in the period. |
| `activity_rate` | number | `active_days` as a percentage of `total_days`, unrounded. |

## `top_repos[]`

| Key | Type | Meaning |
| --- | --- | --- |
| `repo` | string | The repository, as `owner/name`. |
| `count` | number | Events in the repository. |
| `private` | boolean | Whether GitHub reports the repository as private. Internal repositories on GitHub Enterprise count as private. |
| `id` | number | The repository's GitHub database ID, which stays the same through renames; 0 when GitHub reported none. |

## `commits_by_repo[]`

| Key | Type | Meaning |
| --- | --- | --- |
| `repo` | string | The repository, as `owner/name`. |
| `count` | number | Commits in the repository in the period. |
| `private` | boolean | Whether GitHub reports the repository as private. Internal repositories on GitHub Enterprise count as private. |
| `id` | number | The repository's GitHub database ID, which stays the same through renames; 0 when GitHub reported none. |

## `events[]`

| Key | Type | Meaning |
| --- | --- | --- |
| `id` | string | The event's identifier, unique within the report. |
| `type` | string | `PullRequestEvent`, `IssuesEvent`, `PullRequestReviewEvent`, `IssueCommentEvent` (a comment on an issue or pull request) or `CreateEvent` (a repository created). |
| `repo` | string | The repository, as `owner/name`. |
| `repo_private` | boolean | Whether GitHub reports the repository as private. |
| `repo_id` | number | The repository's GitHub database ID; 0 when GitHub reported none. |
| `created_at` | string | When the event happened, as an RFC 3339 timestamp in UTC. |
| `action` | string | `opened` or `closed`. On `PullRequestEvent` and `IssuesEvent` only. |
| `merged` | boolean | Whether the pull request was merged. On a `PullRequestEvent` whose `action` is `closed` only. |
| `number` | number | The pull request's or issue's number. On `PullRequestEvent`, `IssuesEvent` and `PullRequestReviewEvent` only. |
| `title` | string | The pull request's or issue's title. On the same events as `number`. |
| `description` | string | The repository's description. On a `CreateEvent` whose repository has one only. |
| `review_state` | string | The review's state as GitHub reports it, such as `APPROVED`, `CHANGES_REQUESTED` or `COMMENTED`. On `PullRequestReviewEvent` only. |
| `subject_created_at` | string | When the pull request or issue was created, as an RFC 3339 timestamp in UTC. On `PullRequestEvent` and `IssuesEvent` only. |
| `subject_state` | string | The pull request's or issue's state when it was fetched: `OPEN`, `CLOSED`, or `MERGED` for a pull request. The merge and close rates count opened items by it. On `PullRequestEvent` and `IssuesEvent` only. |
